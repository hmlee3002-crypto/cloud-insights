
# Cloud Insights

CSV 데이터를 업로드하고 주요 지표를 분석하는 웹 대시보드 프로젝트입니다.

## Features

- CSV 파일 업로드
- 데이터 미리보기
- 총 방문자 수 및 가입자 수 계산
- 가입 전환율 계산
- 날짜별 방문자 및 가입자 추이 시각화

## Tech Stack

- Python
- Streamlit
- pandas

## How to Run

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the application

```bash
streamlit run app.py
```

브라우저에서 http://localhost:8501 에 접속하세요.
